# 电商图片下载助手（ecom-img-downloader）

AI 编程工具实战培训作业：一个真实可用的 Chrome 扩展，一键抓取电商商品详情页的全部图片，支持单张下载与 ZIP 打包下载；配套静态介绍网页（官网）。

## 功能特性

- **一键抓取**：自动识别普通 `<img>`、懒加载 `data-src`、响应式 `srcset`、背景图片
- **缩略图预览**：弹窗网格展示全部图片，勾选需要的素材
- **单张下载**：悬停图片即可单独下载，文件名自动解析
- **ZIP 打包**：选中多张图片一键打包为 ZIP 压缩包

## 目录结构

```
ecom-img-downloader/
├── manifest.json        # Chrome 扩展清单（MV3）
├── content.js           # 内容脚本：扫描页面图片
├── popup.html           # 弹窗界面
├── popup.js             # 弹窗逻辑（预览/勾选/下载）
├── js/jszip.min.js      # ZIP 打包库
├── icons/               # 扩展图标（16/48/128）
├── website/index.html   # 插件介绍官网（PC + 移动端适配）
└── test/demo-page.html  # 模拟电商详情页（本地验证用）
```

## 安装方法

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角「开发者模式」开关
3. 点击「加载已解压的扩展程序」，选择本项目文件夹
4. 打开任意电商商品详情页，点击工具栏插件图标即可使用

## 本地验证

用浏览器打开 `test/demo-page.html`（模拟电商详情页），点击插件图标，应能抓取普通图、懒加载图、srcset 图与背景图共 8 张。

## 发布

本项目已通过 Git 管理。推送至 GitHub 后在仓库 Settings → Pages 中选择 main 分支即可免费部署官网（静态页面）。

## 说明

- 不收集任何用户数据，图片抓取与打包全部在本地浏览器完成
- 部分平台存在图片防盗链限制，打包时自动跳过失败图片
