三步开始使用

无需任何代码知识，打开浏览器即可

1

打开电商详情页

在淘宝、京东、拼多多等任意电商平台打开一个商品详情页。

2

点击插件图标

点击浏览器右上角的「电商图片下载助手」图标，页面图片自动抓取完成。

3

下载图片

勾选需要的图片，点击「下载选中」或「打包 ZIP」，图片即可保存到本地。

4

完成

图片默认保存到浏览器的「下载」文件夹，随时取用，素材管理更高效。

安装与发布

开发者模式加载，两步搞定

步骤：
1. 打开 Chrome，地址栏输入 chrome://extensions 并回车
2. 打开右上角「开发者模式」开关
3. 点击「加载已解压的扩展程序」，选择本项目的文件夹
4. 打开任意电商详情页，点击工具栏插件图标即可使用

下载插件 ZIP（36 KB）

下载后解压，按上面第 3 步「加载已解压的扩展程序」选择解压出的文件夹即可；也可以直接下载源码仓库自行打包。

常见问题

为什么有的图片下载失败？

部分平台对图片做了防盗链或跨域限制，打包时会自动跳过失败的图片，单张下载一般不受影响。

抓到的图片会保存到哪里？

默认保存到浏览器的下载目录，文件名以图片链接解析出的名称命名，打包下载统一为「电商图片打包.zip」。

插件会不会上传我的数据？

不会。所有图片抓取与打包都在本地浏览器完成，代码开源可查，不收集任何用户数据。

支持哪些浏览器？

支持 Chrome / Edge（基于 Chromium），Firefox 可参考代码自行适配。
